Выполнил: Николай Осипенко
Вариант: 18

Что сделано в работе
Доработал страницу про астрономию и подключил скрипт для работы с DOM и localStorage:

поиск элементов на странице через getElementById, querySelector и querySelectorAll;
проверка существования элементов перед работой с ними;
карточки наблюдаемых объектов (название, тип, яркость) создаются динамически через JS;
кнопка «Добавить объект» создаёт новую карточку, а кнопка «Удалить» внутри карточки удаляет её;
кнопка «Скрыть объекты» скрывает и показывает блок с карточками;
кнопка смены темы переключает тёмное и светлое оформление;
список объектов и выбранная тема сохраняются в localStorage и не сбрасываются при перезагрузке страницы.
